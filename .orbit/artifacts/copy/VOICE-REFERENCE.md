## What this register IS (extract these rules and apply everywhere)
1. **صيغة الجمع للمخاطب المؤسسي**: «منشأتكم»، «أنظمتكم»، «لدعمكم»، «معكم» — never singular/casual.
2. **أفعال مبنية للمعلوم وقوية في البداية**: «ارتقِ»، «يُمكّن»، «يساهم» — verb-led value statements.
3. **مصطلحات القطاع الصحي الدقيقة**: الممارسين · المنشأة · التفعيل · المتطلبات التقنية · التكامل.
4. **بنية ثلاثية**: القيمة → الآلية → الخطوة التالية. Each paragraph does one job.
5. **لا مبالغة ولا علامات تعجب ولا إيموجي** in customer-facing copy. Confidence, not hype.
6. **التشكيل عند اللبس فقط**: «ارتقِ»، «يُمكّن» — used to disambiguate, not decorate.
7. **الخاتمة تعاونية لا إلحاحية**: «يسعدنا التنسيق معكم» — never «اشترك الآن».
8. **صياغة الفائدة بأثر تشغيلي**: تسريع الإجراءات · تقليل العمل اليدوي · تحسين تجربة الممارسين —
   concrete operational outcomes, not adjectives.

## Applying it to the PLATFORM UI (not customer messages)
The UI addresses the internal operator (مدير المبيعات), so:
- Same formality and precision, but **إيجاز أشد**: labels 1–3 words, no full sentences on buttons.
- Terminology must be consistent and singular in meaning across every screen (one word per concept).
- Empty states and explanations use the same «القيمة → الآلية → الخطوة» structure, compressed.
- Numbers and states described neutrally and factually (the honesty rule): «لم يُرسل بعد» not «لا يوجد».
- Avoid the casual/marketing tone that crept in: «ما يستحق وقتك الآن»، «افتح ←»، «جرّبه» etc.
