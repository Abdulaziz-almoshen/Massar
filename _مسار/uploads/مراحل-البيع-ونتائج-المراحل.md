# مراحل البيع ونتائج المراحل — المنتجات الصحية الرقمية

مرجع تنفيذي لدورة بيع التقارير الطبية الرقمية: المراحل، نتيجة كل مرحلة، والإجراء الداخلي المسؤول عنه.

---

## 1. مراحل البيع

| المرحلة | نسبة الإنجاز | معيار الانتقال للمرحلة التالية |
|---|---|---|
| تواصل أولي | 10% | وصلنا لصاحب القرار وأبدى اهتمامًا مبدئيًا |
| اكتشاف الحاجة | 25% | تأكدت الحاجة والحجم وصاحب القرار والميزانية |
| عرض المنتج | 45% | تم تقديم المنتج وقبول العميل للقيمة |
| التقييم التقني | 65% | اجتاز التكامل مع صحة/صحتي ومتطلبات الأمن |
| عرض السعر | 80% | تم إرسال عرض سعر مقبول مبدئيًا |
| التفاوض والاعتماد | 90% | توافق على الشروط ودخول التعاقد/المشتريات |
| إغلاق – ربح | 100% | تم التوقيع والاعتماد |
| إغلاق – خسارة | 0% | اعتذر العميل (سجّل السبب) |

المرحلتان **التقييم التقني** و**التفاوض والاعتماد** هما الأطول تعثّرًا؛ اضبط لهما تنبيهًا زمنيًا عند الركود.

---

## 2. نتيجة كل مرحلة والإجراء

حقلان مترابطان في فرص البيع: **نتيجة المرحلة** (قائمة مترابطة تتغيّر حسب المرحلة) و**سبب النتيجة**.

### المرحلة 1 — تواصل أولي
| نتيجة المرحلة | السبب | الإجراء |
|---|---|---|
| مهتم | رأى قيمة أولية | انتقال للاكتشاف |
| مؤجّل | مشغول / ليس أولوية | إعادة جدولة تواصل |
| وصل لصاحب القرار | البوابة موظف غير مخوّل | تحديد صاحب القرار |
| غير مهتم | لا حاجة مدركة | إغلاق – خسارة (لا حاجة) |

### المرحلة 2 — اكتشاف الحاجة
| نتيجة المرحلة | السبب | الإجراء |
|---|---|---|
| حاجة مؤكدة | ألم واضح + ميزانية | انتقال للعرض |
| حاجة غير مكتملة | نقص معلومات / صاحب قرار | اجتماع استكشاف إضافي |
| لا ميزانية حالياً | قيد مالي / دورة ميزانية | متابعة مجدولة لاحقاً |
| لا حاجة فعلية | الوضع الحالي كافٍ | إغلاق – خسارة |

### المرحلة 3 — عرض المنتج
| نتيجة المرحلة | السبب | الإجراء |
|---|---|---|
| مقبول | القيمة والتكامل مقنعان | انتقال للتقييم التقني |
| يحتاج توضيح تقني | أسئلة اعتماد / تكامل صحتي | إرسال توضيح + وثائق التكامل |
| اعتراض على الجدوى | لم يرَ فرقاً عن نظامه | معالجة اعتراض بحالة استخدام |
| مرفوض | لا ملاءمة | إغلاق – خسارة |

### المرحلة 4 — التقييم التقني
| نتيجة المرحلة | السبب | الإجراء |
|---|---|---|
| اجتاز التقييم | التكامل والأمن مقبولان | انتقال لعرض السعر |
| بانتظار الجهة التقنية | مُحال ولم يُرد | تحديد سقف زمني + متابعة |
| متطلبات أمن إضافية | اشتراطات أمن معلومات | تجهيز مستندات الامتثال |
| فشل التكامل | قيد تقني غير قابل للحل | إغلاق – خسارة (تكامل) |

### المرحلة 5 — عرض السعر
| نتيجة المرحلة | السبب | الإجراء |
|---|---|---|
| مقبول | السعر ضمن التوقع | انتقال للتفاوض / الاعتماد |
| يحتاج تعديل الباقة | نطاق أوسع / أضيق | إعادة تسعير الباقة |
| اعتراض سعري | تكلفة عالية مدركة | إعادة ربط بالقيمة قبل الخصم |
| مقارنة بمنافس | يوازن عروضاً أخرى | تمييز تنافسي + دليل قيمة |

### المرحلة 6 — التفاوض والاعتماد
| نتيجة المرحلة | السبب | الإجراء |
|---|---|---|
| متفق مبدئياً | توافق على الشروط | تجهيز التعاقد |
| يحتاج تعديل العقد | بنود قانونية / مدة | مراجعة وتعديل مع القانونية |
| بانتظار المشتريات | دورة موافقات داخلية | متابعة مسار المشتريات |
| مرتبط بدورة الميزانية | قيد زمني مالي | جدولة إغلاق حسب الميزانية |

### المرحلة 7 — الإغلاق
| نتيجة المرحلة | السبب | الإجراء |
|---|---|---|
| ربح | توقيع واعتماد | بدء التفعيل فوراً |
| خسارة – السعر | تكلفة غير مقبولة | تسجيل + مراجعة تسعير |
| خسارة – منافس | اختار بديلاً | تسجيل + تحليل تنافسي |
| خسارة – تأجيل | أُجّل لسنة قادمة | إعادة تفعيل مجدولة |
| خسارة – تكامل | فشل التكامل التقني | تسجيل + مراجعة تقنية |

## 3. الإجراء الداخلي

يُسجَّل كل إجراء داخلي (نشاط) بحقلين للمسؤولية:

- **الإدارة المسؤولة** — قائمة: إدارة المنتج · المبيعات · التقنية · القانونية · المشتريات · أمن المعلومات.
- **الشخص المسؤول** — بحث (Lookup) للمستخدمين، اختياري.

بهما تُفلتر الإجراءات المعلّقة حسب الإدارة، ما يعالج تعثّر مرحلتي التقييم التقني والتفاوض حيث تنتقل المسؤولية بين الإدارات.

---

## 4. التطبيق في Zoho

- حقل **نتيجة المرحلة**: Dependent Picklist مرتبط بحقل المرحلة.
- حقل **سبب النتيجة**: مرتبط بالنتيجة المختارة.
- حقلا **الإدارة المسؤولة** و**الشخص المسؤول**: في وحدة الأنشطة.
- **شارة لونية** للنتيجة: مقبول = أخضر · يحتاج إجراء = كهرماني · خسارة = أحمر.

تقارير جاهزة بهذه الحقول: الفرص المتوقفة بانتظار المشتريات · الفرص التي تحتاج تعديل عقد · الإجراءات المعلّقة على التقنية · الخسائر بسبب التكامل.
